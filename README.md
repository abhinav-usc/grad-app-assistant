# Grad app assistant
A tool to help students with PhD and Masters Program 

Currently attuned for me and my friend, Ana.

## Quick setup

1. Install dependencies: ```npm install```
2. Add ```.env``` file to /server and put ```js ANTHROPIC_API_KEY="your key"```
3. Change the name(s) in the 
3. Open two terminals and run ```console npm run dev``` on one and```cd server  && console node index.js``` from the other terminal window.
